T-Engine 4

Tales of Maj'Eyal（ToME4）背後的 C + Lua 雙層 roguelike 引擎
底層 C/SDL2/OpenGL 顧效能，上層 Lua 寫玩法，模組以 zip 封包發佈

— analysis/t-engine · v1.7.6 · 架構分析 6 篇 + 開發教學 17 篇 —

Lua 5.1 / LuaJIT SDL2 + OpenGL PhysFS 虛擬檔案系統 .teae / .team / .teaa 封包 Roguelike
T-Engine 4 = 一個「引擎歸引擎、遊戲歸遊戲」分得非常乾淨的架構： 引擎核心（engine/*.lua）提供實體、地圖、AI、存檔等通用系統， 遊戲模組（modules/tome 等）只以資料定義與類別覆寫組出完整遊戲—— 這也是它的 Addon 生態（hooks / superload / overload）能成立的原因。
整體分層架構

遊戲模組（Lua）

modules/tome、modules/example… — 玩法內容、職業、地區、任務，全部資料驅動

▼

引擎核心（Lua）

engine/*.lua — OOP（class.lua）、實體系統、地圖、UI、AI、存檔、Resolver 延遲計算

▼

C ↔ Lua 橋接層（core.* API）

core_lua.c、display_sdl.c、map.c、shaders.c… — 效能敏感操作下沉到 C

▼

底層 C 函式庫

SDL2、OpenGL/GLEW、PhysFS、LuaJIT/Lua 5.1、libvorbis、zlib、LuaSocket…
