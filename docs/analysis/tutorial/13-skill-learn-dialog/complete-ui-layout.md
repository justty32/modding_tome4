整個 Dialog 標題為「技能學習」，主體為左右雙欄，底部有 `setupUI` 自動加入的「關閉」按鈕：

| 區塊 | 元件 | 內容 |
|------|------|------|
| 左欄 | `TreeList`（欄位：天賦名稱／等級／狀態） | 依天賦樹分組可摺疊，例如「▼ 戰鬥技巧」下列出近戰攻擊 `2/5 可學`、防禦姿態 `0/5 可學`、連擊 `0/5 未達`；「▼ 魔法」下列出火球術 `0/5 可學`、冰錐術 `3/5 已滿`、閃電鏈 `0/5 無點` |
| 右欄（上） | `TextzoneList`（選中天賦的說明） | 天賦名稱、`等級：0/5｜類型：combat/…`、前置需求（如「等級 5 以上」）、天賦說明文字 |
| 右欄（下） | 資訊列 + `Button` | 「可用天賦點數：2」＋〔學習（消耗 1 點）〕按鈕 |
| 底部 | `Button`（自動） | 〔關閉〕 |

狀態欄的四種值：**可學**（滿足條件）、**未達**（前置不足）、**已滿**（達等級上限）、**無點**（天賦點不夠）。
