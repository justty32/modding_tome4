mod 產物目錄 — self_mods/

8 個用本工具鏈實際做出來的 ToME4 addon。一句話介紹取自各自 init.lua 的 description 欄位；完整內容請點卡片連到 init.lua 或原始碼目錄。 狀態標籤依 session_log/ 的最新實機驗證紀錄整理，非全部逐次覆核。

職業與系統

tome-runewright — 盧恩術士

把銘文系統從消耗品插槽變成職業核心的奧術職業：他不是使用符文，他書寫符文。 觸發任何銘文都會累積「符文充能」，特定銘文組合會產生「共鳴」，帶來湧現式的被動效果。含符文盤 UI 面板。

tome-companions — 同伴系統

「契約召募」天賦（建角自動學會）：對準附近非傳奇生物即可收為契約夥伴—— 加入隊伍成為可操控同伴、立即拉到同級並隨主人升級成長、完全免疫主人造成的傷害（含 AOE）但仍受敵傷。

tome-crafting — 工匠之藝

附魔與煉製，全職業通用。建角自動學會兩個天賦：附魔（寶石鑲入武器／防具，沿用煉金師 Imbue Item 機制）、煉製（消耗 3 顆寶石煉出 1 顆隨機寶石，材料→產物配方骨架）。

tome-camp — 營地系統

持久的私人據點（Homestead Camp）。「返回營地」天賦：野外傳送到私人營地並在營火旁全體回血； v0.2 大地圖入口貼在德斯城旁；v0.3 儲物箱；v0.4 建造系統（花錢蓋儲物箱／營火）。狀態持久存檔。

世界與地圖

tome-runeisles — 符文諸島

全新大世界地圖＋三階段主線劇情。德斯城西側符文石環通往北方冰封海上的群島； 古代刻名師以符文石陣鎮壓「無銘之物」，石陣正在崩解。承接盧恩術士設定但不需安裝它也能遊玩。

tome-orario — 歐拉麗

「在地下城邂逅」風味異世界。德斯城旁的門通往迷宮都市歐拉麗——中央廣場 hub 四面是 冒險者公會、酒館、市集與眷族據點，中央大迷宮「巴別塔」。世界觀取材但劇情人物不刻意還原。

物品與 NPC

tome-relics — 失落挖掘者的遺物

考古主題的物品／神器 addon：拓印牆上銘文的燈、成套穿戴才顯真章的護目鏡與手套、 會「記錄」每次擊殺愈用愈利的銘紀之鎬，以及可能出現在同年代武器防甲上的考古匠人詞綴。純加法，不覆寫原版檔案。

tome-talent-tutor — 技藝導師

大地圖 NPC（德斯城附近），免費傳授遊戲中全部約 300 棵技能樹。對話依大類分頁， 技能樹清單在對話開啟時動態產生，其他 addon 新增的技能樹也會自動出現。
