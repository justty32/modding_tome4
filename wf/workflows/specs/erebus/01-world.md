## 1. 五分鐘版世界觀

太初只有真神 **The One**。祂造了天堂與 **21 位天使**，命他們共同創造世界 **Erebus**。
天使 **Agares** 不甘失去創造之力而墮落，唆使另六位一同背叛。
The One 無法親臨（祂的聖潔會毀掉整個造物），於是**把 21 位天使全部逐出天堂、封閉天路**。

被逐的天使自封為「神」——跟隨 Agares 的成了惡神，對抗他的成了善神，只想維持世界運轉的成了中立神。
**他們從不告訴凡人真相。** 所以：這個世界所有的宗教戰爭與末日，
**其實是一場天使的家庭內戰，凡人只是被拿來代打的棋子。**

世界史分五個時代，每個時代都由一場神級災變終結。**遊戲發生在第四紀「重生時代」**——
寒冬之神已死、魔法回歸、諸國從廢墟重建，**而末日的陰影正在逼近**。

## 2. 玩家是誰

**不鎖主角。** ToME 的自訂角色直接就是答案——FFH 本來就沒有單一主角。

你是重生時代的一個冒險者。你不是天選之人、沒有預言、沒有人在等你。
你只是活在一個**倒數計時已經開始**的世界裡，而且你的所作所為會讓那個數字動。

> 這是本設計最省事也最正確的一點：**永久死亡完全不需要解釋**。
> 你死了，世界繼續倒數，下一個冒險者接著走。

## 3. 核心張力：一條往上爬的數字

重生時代的反派不是某個國家，是 **末日計數器（Armageddon Counter，簡稱 AC）**。

它是一個 0–100 的全域進度條。**世界會照它的數字改變**：

| AC | 世界發生什麼 |
|---|---|
| 30 | **枯萎（Blight）**：瘟疫蔓延，野外生物病變，部分 NPC 死去 |
| 40–70 | **四騎士依序降臨**：征服 → 戰禍 → 瘟疫 → 死亡。四個在世界上遊蕩的超級威脅 |
| 80 | **地獄地形開始蔓延**：地圖一塊一塊變成地獄 |
| 90 | **憤怒化身現世**：可挑戰的最終存在 |
| 100 | **末日**：天降火、海沸騰、地獄與 Erebus 合一 |

三股勢力圍繞這個倒數角力，**它們都不是純粹的反派或好人**：

| 勢力 | 要什麼 |
|---|---|
| **Sheaim（謝姆）** | 召喚師之國，**唯一受惠於高 AC 的文明**，主動推世界走向毀滅 |
| **Infernal（地獄魔軍）** | 有人打破諸神盟約召來的地獄軍，把領土化為地獄地形 |
| **Illians（伊利安）** | 想重啟冰河時代，其少年領袖立志封神成為新的寒冬之神 |

對抗它們的是律法狂熱的 **Bannor**、守護記憶的 **Elohim**、天使軍團 **Mercurians**。
而 **Grigori** 是特別的一支：**他們否定諸神**，主張那些「神」根本不是神——**他們是對的**。

## 4. 取材範圍：搬什麼、砍什麼

**這一節是硬性的。實作者不准擴大取材。**

**使用者 2026-08-06 定調：復刻全部——一個完整的世界，一個文明有很多城市。**
所以下表的原則是「**世界觀與內容全搬，遊戲類型不搬**」。

| 素材 | 決定 | 理由 |
|---|---|---|
| 末日計數器與它的門檻災變 | **全搬** | 這是整個 addon 的心臟（[02](02-mechanics.md)）|
| 21 種法球（Mana Spheres） | **全搬** | 天然對應 ToME 技能樹 |
| 全部宗教教團 | **全搬** | 每個一棵教團樹 + 陣營關係 |
| **全部文明** | **全搬**，**且每個文明有多座城市** | 見 §4.1 |
| 具名英雄與神器 | **全搬**，當守關者與獎勵 | `characters.md` / `items.md` 已列好，拆包後還有一手資料 |
| 諸神（21 天使） | **只當 lore 與宗教背景，不出場** | 盟約規定諸神不得親臨 Creation——**設定本身就幫我們省掉做神明 boss 的工** |
| The One 的真相 | **搬**，當終局揭露 | 全作最大的劇透，也是最好的結尾 |
| 四騎士 | **全搬**，做成隨 AC 降臨的超級威脅 | 機制上最有戲 |
| 官方戰役的**角色與事件** | **搬**，當背景與支線 | 素材已在 `events.md` / `timeline.md` |
| **建城／外交／科技樹／文化勝利／回合制戰略** | **全砍** | 那是《文明》的**遊戲類型**，不是它的世界。見 [README](README.md) 前提 2 |
| **AI 文明互相開戰的模擬** | **全砍** | 需要大規模陣營對抗機制。文明之間的衝突用任務與世界狀態表現 |
| **官方戰役的關卡結構** | **不逐一重現** | 那是 Civ 的地圖與勝利條件。取其敘事，不取其關卡 |

### 4.1 「一個文明有很多城市」的意思

這是規模上最重的一條決定，也是**整個量產計畫的形狀**：

- **文明**是分組，不是內容單元。一個文明 = 一組共享派系、宗教、美術風格、語氣的城市。
- **城市**才是內容單元。每座城市有自己的 zone、NPC、任務、周邊地城。
- 所以內容量是 **文明數 × 每文明城市數**，而不是文明數。
- **好消息**：拆包 FFH 本體後，**城市清單與座標可以直接從它的地圖檔抄**
  （Civ4 的 WorldBuilder 存檔逐格列出城市），見 [09](09-source-mod-unpack.md)。
  我們不必發明城市，只要把原作已經放好的城市填成 ToME 的 zone。

⚠️ 這個規模是**原版 ToME 的數倍**。它能成立的唯一前提是
[03](03-content-model.md) 的填表模型撐得住、而且能平行量產。
分期與誠實的規模估算見 [04](04-buildout.md)。

## 5. 地理

Erebus 自己的世界地圖，**照原作的地圖復刻**（拆包後直接轉換，見 [09](09-source-mod-unpack.md)）。

地圖上有這幾類東西：

| 類別 | 數量 | 性質 |
|---|---|---|
| **登陸點** | 1 | 玩家從 Eyal 傳送門抵達的中立港市，補給與情報中心 |
| **文明領地** | 全部文明 | 每個領地內有**多座城市**，共享派系與風格 |
| **城市** | 每文明數座 | 內容單元：一個 zone + NPC + 任務 + 周邊地城 |
| **地城** | 城市周邊與野外 | 遺跡、地下家園、神殿、巢穴 |
| **法力節點** | 散佈野外 | 取得法球、換技能樹的地方（[02](02-mechanics.md)）|
| **地獄裂縫** | AC 高才出現 | 隨 AC 上升在地圖上長出來的高難度區域 |
| **軍團／團體** | 在大地圖上移動 | 大地圖是戰略尺度，上面走的是遠征軍、巡禮隊、劫掠團、地獄軍先鋒——**不是單一角色**（[02 §5.5](02-mechanics.md)）|

**文明之間、城市之間都不強制順序**，玩家愛先去哪就去哪——
這既是 roguelike 的自由度，也是內容能平行量產的前提。

## 6. 主線：三幕

刻意做短。**主線是骨架，肉在各文明的支線裡**，這樣沒做完的文明不會讓主線斷掉。

| 幕 | 在哪 | 發生什麼 |
|---|---|---|
| **一・抵達** | 登陸點 | 你到了 Erebus。第一次看到末日計數器，也第一次被告知它代表什麼 |
| **二・遊歷** | 各文明領地，任意順序 | 取得法球與宗教。**逐步發現各方勢力都在拿這個世界下注**，而你的每個選擇都在動那條數字 |
| **三・終局** | 依 AC 與你的選擇分岔 | 見 §7 |

**揭露的核心**（由 Grigori 一線帶出）：**你信的神不是神，是被逐出天堂的天使。**
而真天堂自創世起就對所有人關閉——諸神給凡人的「天堂」全是仿冒品。

## 7. 三個結局

都在終局 zone 分岔，機制上是 quest 分支 + 不同收尾 lore。

| 結局 | 條件 | 世界變成什麼 |
|---|---|---|
| **阻止末日** | 把 AC 壓回低檔，並擊敗已降臨的威脅 | 倒數停住。世界沒有變好，只是還沒結束 |
| **推動末日** | 讓 AC 到 100 | 天降火、地獄與 Erebus 合一。**角色以世界毀滅告終**——這是一個結局，不是失敗 |
| **盧諾塔之壇** | 建成祭壇，把「諸神不是神」推到邏輯終點 | 真相公開。諸神最怕的一天到來 |

> **「推動末日」必須是一個正當的、玩得到的結局，不是輸。**
> FFH 的精神就是沒有正確結局，這一條不要為了做成「善良通關」而改掉。

## 8. 語氣與文案基調

寫給實作 agent 的硬性風格約束——**這是防止弱模型把味道寫掉的護欄**：

- **諸神很有人味，而且都在說謊或墮落。** 連最「正義」的律法之神都在掩蓋真相、殺自己的祭司滅口。
  寫神職 NPC 時，要寫得出那份心虛。
- **凡人不知道真相。** 除了 Grigori 與少數異端，NPC 講起「神」是虔誠的、日常的。
  **不要讓每個 NPC 都在暗示劇情。**
- **不要史詩腔。** 這個世界已經被毀過三次了，人們對災難的態度是疲憊與麻木，不是悲壯。
- **末日計數器在遊戲內不是一個數字，是徵兆。** NPC 不會說「AC 現在是 45」，
  他們會說「井水又黑了」「東邊的村子沒人回來了」。**數字給玩家看，徵兆給世界看。**
- 名字直接沿用原作專有名詞（Bannor、Grigori、Sheaim…），**但所有描述與對白都要原創重寫**，
  不逐字搬原文（見 [README](README.md) 著作權註記）。
