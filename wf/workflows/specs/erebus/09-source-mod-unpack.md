## 1. Civ4 mod 的一般結構（預期）

Civ4 的 mod 是**純檔案目錄**，不是封裝格式，拆包等於直接讀。預期會看到：

| 目錄 | 內容 | 對我們的價值 |
|---|---|---|
| `Assets/XML/Text/` | 全部遊戲文字（civilopedia、單位說明、劇情字串），XML 格式 | ★★★ **最有價值**。世界觀文本的原始出處 |
| `Assets/XML/Civilizations/`、`Units/`、`Buildings/` | 文明、單位、建築的定義表 | ★★ 文明清單、單位名、陣營關係的權威來源 |
| `PublicMaps/`、`PrivateMaps/` | 地圖檔（`.CivBeyondSwordWBSave` 等 WorldBuilder 存檔） | ★★★ **世界地圖**。WorldBuilder 存檔是**純文字**，逐格列地形 |
| `Assets/Python/` | 事件、戰役腳本 | ★ 可看末日計數器等機制的原始邏輯 |
| `Assets/Art/` | 美術資產 | ★ **部分可用**，見 §2.5 |

⚠️ 上表是**根據 Civ4 modding 的一般慣例推測**，FFH 實際長怎樣要拆開才算數。
拆完第一件事是回來把這張表改成事實。

## 2. 世界地圖：這是最大的一筆

**Civ4 的 WorldBuilder 存檔是純文字的逐格資料**（每格的地形、地貌、資源、城市、單位）。
如果 FFH 附了 Erebus 的成品地圖，那我們就有一張**現成的、原作者畫的大陸**。

轉換路線：

```text
.CivBeyondSwordWBSave（逐格文字）
  → 寫一支一次性轉換腳本，把地形碼對映成 ToME 的地磚
  → 產出 ToME 的 ASCII 大地圖（data/maps/worldmap.lua）
```

- ToME 的大地圖就是一張 ASCII 圖 + `defineTile` 對映（見 [07-skeleton.md](07-skeleton.md)）。
  **兩邊都是逐格資料，這個轉換是機械式的**，很適合交給 sonnet 寫腳本。
- 尺寸要縮：Civ4 的地圖通常比 ToME 大地圖大得多，需要降採樣。**縮放比例是要決定的事**。
- 地形種類要對映：Civ4 的 terrain/feature 兩層 → ToME 的一層地磚 + `add_mos` 疊加。

> **這一步能省掉「畫一張大陸」的全部工作，而且畫出來的是原作的真地圖。**
> 排進 v0.1，優先度很高。

## 2.5 美術：2D 的可以用，3D 的不行

使用者 2026-08-06 表示圖像有需要也可以用。技術上要分兩類看：

| 資產 | Civ4 的格式 | 能不能用 |
|---|---|---|
| **按鈕／圖示**（單位、建築、宗教、法球、升級） | `.dds` 2D 貼圖，通常 64×64 或 128×128 | ✅ **可以直接用**。`magick` 轉 PNG 即可，尺寸剛好對得上 ToME 的天賦／物品圖示 |
| **介面元件、宗教符號、地圖裝飾** | `.dds` 2D | ✅ 同上 |
| **單位模型** | `.nif` 3D 模型 + 貼圖 | ❌ **不能用**。ToME 是 2D 俯視，3D 模型沒有可用的角度 |
| **地形貼圖** | `.dds`，但是給 3D 地表用的 | ⚠️ **要試**。可能可以當地面材質，但透視與接縫不保證 |

**所以美術的實際結論**：圖示類幾乎白撿一整套，角色與地形貼圖仍以**沿用 ToME 原版**為主
（原版 `npc/` 有 636 張現成人形貼圖，成本 0）。

拆包後要做的第一件事是**確認 `.dds` 轉 PNG 之後透明通道正不正確**——
本 repo 對 alpha 有既定的驗收方式（`magick x.png -alpha extract` 看 minima），
見 [assets.md](../../agent-driving/assets.md)。

## 3. 文本：直接用還是改寫

使用者的意思是文本可以直接用。技術上完全可行（XML 抽字串是機械工作，
`sub_proj/zh_mods/` 已經有一整套抽取／翻譯／驗證的管線可以參考）。

實務上分兩種用途：

| 用途 | 做法 |
|---|---|
| **當素材**：設定、專有名詞、事件、數值、陣營關係 | 直接用。這些是事實性資訊 |
| **當遊戲內文字**：對白、描述、lore 全文 | 建議改寫。理由不只是著作權（見 [README](README.md)），還有**體裁不合**——civilopedia 是百科條目，塞進 ToME 的對話框會很難讀 |

自己玩怎麼用都行；要公開發佈才需要在意前者。這是使用者的決定，不是 agent 的。
