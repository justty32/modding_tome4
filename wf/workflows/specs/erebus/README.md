           分期與平行分工寫死、待複驗清單列出

> **取材**：《Fall from Heaven》（《文明 IV》的黑暗奇幻 total conversion mod）的世界 **Erebus**。
> 素材來源是使用者自己的結構化抽取庫 `C:/code/mine/gameplots/results/Fall_from_Heaven/`
> （synopsis／timeline／characters／factions／places／items／concepts／events 全套，約 2000 行）。
>
> **本份由主 agent 在使用者授權下擔任最高層決策者定案**（2026-08-06）。
> 取材範圍、核心機制、主線、結局都已拍板。實作者要決定的是「填哪些內容」，不是「這個世界是什麼」。

## 一句話

**一群被真神逐出天堂的天使自封為神，把世界 Erebus 當棋盤打了五個時代的代理戰爭。
你是重生時代的一個冒險者，而末日計數器正在往上爬。**

## 為什麼是這個題材，而不是原創世界

| 理由 | 具體 |
|---|---|
| **世界觀已經結構化好了** | gameplots 那套 extract 產物就是內容表的半成品，弱模型是**填表**不是創作 |
| **FFH 沒有單一主角** | 它是一套世界觀 + 多文明背景 + 戰役切片。**這正好契合 roguelike**：玩家是自訂角色，不必當天選之人 |
| **它的招牌機制天生適合 roguelike** | 末日計數器（見 [02](02-mechanics.md)）是一個全域進度條，一條數字驅動整個世界變化——量產友善到不可思議 |
| **文明是天然的重複單元** | 一個文明 = 一城一地城一派系一任務鏈一英雄一神器。切得乾淨，適合一隻 agent 做一個 |

⚠️ **著作權**：FFH 是他人創作的 mod，Erebus 的專有名詞與設定屬於原作者。
照本 repo 既有立場（[orario spec §6.1](../orario-complete-design.md)）：
**不逐字搬運任何原文**，在該世界觀下寫原創對白與描述；發佈時在 addon description 標明取材出處。
這是同人作品的常規做法，但決定要不要公開發佈是使用者的事。

## 世界是三層的

這是玩起來最不一樣的地方，也是內容能無限長出來的原因：

| 層 | 是什麼 | 上面活動的 | 怎麼來的 |
|---|---|---|---|
| **大世界地圖** | 一格 = 一片地方 | 軍團、團體 | 一張，從 FFH 原作抄 |
| **中層區域地圖** | 一格 = 一小塊地 | 團體，也有個人；散落村落與遺跡 | **就地生成** |
| **實際活動地圖** | 一般 roguelike 尺度 | 個人、單場戰鬥 | 城市區塊與地城是**手寫**；從中層鑽下來的是**生成** |

大地圖上沒有城市的荒野格子，用**「進入區域」技能**就能就地生成一張中層地圖，
內容由 **地形 × 文明勢力範圍 × 城市勢力範圍 × 末日計數器** 算出來。
中層裡的荒野格再往下鑽一次，就是實際活動地圖。**三層到此為止。**

臨時地圖跟著存檔走、有上限、太久沒去的會被淘汰；
而**在裡面發現的具名地點會固化回大地圖**——你是在把一張空白的大陸變成有標記的大陸。

細節在 [02 §2.5](02-mechanics.md)，資料表在 [03 §2.7–2.8](03-content-model.md)。

## 四個已經定死的前提

1. **自成一張新世界地圖。** Erebus 是自己的 worldmap zone，不疊在 Eyal 上。
   技術前例是 `self_mods/tome-runeisles/`（新大地圖 + 城鎮 + 兩地城 + 主線，887 行），進入方式沿用它。
2. **不做 4X。** 不建城、不外交、不科技樹、不回合制戰略。
   FFH 是《文明》的 mod，但我們做的是 roguelike——**搬設定與機制，不搬遊戲類型**。
   這一條要明著寫進契約，弱模型看到「文明」兩個字就會想做建城。
3. **與 `tome-orario` 無關。** 不共用檔案、不共用 id、不互相依賴。
4. **不做過場動畫。** 劇情用 chat / quest / lore / zone 事件四種載體。
   `tome-director` 至今沒有任何真實劇情用過它，不當前提。
