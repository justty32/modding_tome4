# 美術與音效怎麼交代

← [agent-driving](README.md)

這些規則**開工前就要寫進契約**，否則每個 agent 都會各自撞一次。
引擎機制面的完整說明在 [docs/knowledge/visuals-and-sounds.md](../../../docs/knowledge/visuals-and-sounds.md)。

三類資產三條路，**開工前就寫進契約**，不要讓每個 agent 各自摸索一次：

| 資產 | 怎麼來 |
|---|---|
| 動態特效／粒子 | **自己寫 Lua**（它本來就是 Lua 不是圖）|
| 靜態貼圖 | **`agy` 生圖** + 補 alpha |
| 音效 | **只能借原版**（`agy` 沒有音訊生成能力，實測問過）|

## `agy` 生圖的三個坑（都要寫進契約）

1. **它存到自己的 scratch 目錄**（`~/.gemini/antigravity-cli/scratch/`）而非工作目錄，要自己 `cp`。
2. **產出的 PNG 沒有 alpha 通道**，要自己補。
3. **它會宣稱生成成功但實際沒有產出檔案。** 生完一定要 `ls` 確認檔案真的在、
   而且 mtime 是新的——不要採信它的自我回報。

## ⚠️ 透明度：`srgba` 不等於有透明

**這是我自己犯的錯，寫在這裡免得重蹈。** 契約原本只要求檢查

```bash
magick identify -format '%[channels]\n' x.png   # 看到 srgba 就收工 ← 不夠！
```

`srgba` 只證明**通道存在**，不證明**有被用到**。實測 `tome-witchwood` 的地形圖
全是 `alpha min=255 mean=255`——通道有、透明度全無。因為 `-transparent white`
對「滿版材質、根本沒有白底」的圖什麼都去不掉。怪物圖碰巧成功，只因為它的構圖真有白底。

**正確的驗收**：

```bash
magick x.png -alpha extract -format 'min=%[fx:minima*255] mean=%[fx:mean*255]\n' info:
# 要透明的圖：min 必須是 0
```

## 三類貼圖，透明度需求不同

| 圖類 | 要透明？ | 為什麼 |
|---|---|---|
| **地面 floor** | **不要** | 要滿版不透明才能無縫平鋪，有洞會露出黑底 |
| **牆／樹** | **要** | 原版樹是兩層疊的：底圖草地 + `add_displays` 以 `z=3` 疊樹（`M/data/general/grids/forest.lua:76`、`M/mod/class/Grid.lua:251-255`）|
| **怪物／NPC／物件** | **要** | 疊在地面格上 |

地面圖另有一條**生圖 prompt 的關鍵**：要明講「無縫平鋪、正上方俯視、打光平均無方向性陰影、
不要單一焦點物件、色調壓低」。不講的話生成模型會給你一張有構圖的風景插畫，當地磚必然難看。

還有一條**檔名規則**必須交代：自製圖放 `overload/` 是 prepend 掛在 VFS 根，
**撞名會靜默覆蓋原版、全遊戲生效**。所以檔名一律加 addon 專屬前綴
（`R/deathknight` 全加 `_raz` 就是為此）。細節見 [visuals-and-sounds](../../../docs/knowledge/visuals-and-sounds.md)。


## 去背：用洋紅 key color，不要事後硬去

**實測結論（2026-08-01 第二版地形圖）。** 要透明的圖，別指望生完再去背——
直接叫生成模型**畫在純洋紅底上**，再用 key color 去掉：

```text
背景必須是純洋紅色 #FF00FF 的實心底色（去背 key color，
不允許任何其他顏色、漸變、陰影、雜訊）；主體不許含任何接近洋紅的像素。
單一物件置中佔畫面約 60-70%，輪廓清晰。
```

```bash
magick in.png -fuzz 12% -transparent '#FF00FF' out.png
```

| 做法 | 結果 |
|---|---|
| 洋紅底 + `-fuzz 12%` | **1 次成功**，min=0 |
| 背景是漸變霧氣，事後 `-fuzz 20%` 硬去 | **失敗**——色相與主體太近，主體大塊像素被誤殺，只剩零散雜色 |
| 背景是均勻深色，取樣後 `-fuzz 12%` | 1 次成功（背景夠均勻時可行）|

所以：**新生的圖一律要求洋紅底；只有背景本來就均勻的舊圖才值得事後補去背。**

去背後除了 `alpha minima` 還值得再做兩道複驗（那個 agent 自己想到的，很好用）：

1. **不透明像素直方圖**——確認剩下的主體是「大塊色群」而非零散殘渣
2. **洋紅特徵掃描**（`R≈B>G`）——確認邊緣沒有殘留粉紫色圈

## 地面圖的成功 prompt

地面**不要**洋紅底（它要滿版不透明）。關鍵是壓掉「插畫感」：

```text
正上方俯視（top-down orthogonal），不要透視、不要地平線；
無縫平鋪，左右與上下邊緣要能接起來；
打光平均，不可有方向性陰影或高光；
不要單一焦點物件、不要構圖、不要邊框，就是一片均勻材質；
色調壓低去飽和，怪物要疊在上面還看得清楚。
兩張變化圖的色調必須一致，因為會混用。
```
