tome4-modkit

讓 AI agent 自主開發 Tales of Maj'Eyal（ToME 4）addon 的工具鏈與知識庫
開發 → 靜態檢查 → 打包 → 佈署 → 無頭測試，一條龍

— 本 repo 主體 · HTML 導覽層（.md 才是唯一真相來源）—

Lua 5.1 / LuaJIT Bash 工具腳本 Xvfb 無頭測試 ToME 1.7.6 給 agent 用，不是給人用的 GUI
這不是給人操作的圖形工具，是給 agent 用的一條龍：.claude/skills/ 描述何時該做什麼、 tools/ 提供冪等的可重複動作、knowledge/ 記錄引擎真實行為（附 檔案:行號）。 已用它產出 8 個實戰 addon（見 mod 產物目錄）。
5 分鐘上手 — 做一個 addon 的最短迴圈
1

先讀 knowledge/，不要憑記憶寫 API

依 引擎知識庫 索引找對應主題；沒有就去原始碼 grep，讀完補回 knowledge/。

2

tools/lint.sh <addon> — 語法 + init.lua 欄位

證明語法正確、欄位語意正確；證明不了任何 runtime 行為。

3

tools/deploy.sh <addon> --home <scratch> → tools/verify.sh <addon>

目錄形式佈署到拋棄式 scratch home，Xvfb 無頭啟動一次，確認 addon 被載入、無 Lua Error。

4

觸及遊戲邏輯 → tools/playtest.sh start/do/shot/lua/stop

verify 綠燈 ≠ 做完。真的建角、真的按技能、真的看數值，抓「載入成功但行為錯誤」的坑。

5

交付前 tools/deploy.sh <addon>（不帶 --home）

佈署到真 ~/.t-engine/4.0/addons/。verify/playtest 用的都是拋棄式 home，不會自動進到這裡。

完整管線圖與各關卡的「證明了什麼／證明不了什麼」表 → 工具鏈頁； 原始 SOP → workflows/addon-dev/README.md
